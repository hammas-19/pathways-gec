# GEC Pathways - Study in China

A modern, comprehensive website for Global Educational Consultants (GEC) - a doctor-led China-based education consultancy specializing in MBBS programs and international student placement.

## 🚀 Features

- **Modern Design**: Built with Nuxt 3 and Tailwind CSS
- **Mobile-First**: Fully responsive design optimized for all devices
- **SEO Optimized**: Meta tags, schema markup, and semantic HTML
- **Performance**: Fast loading times with optimized images and code splitting
- **Comprehensive Content**:
  - Homepage with 12 sections
  - Program pages (MBBS, Engineering, Business, etc.)
  - Country-specific guides (Pakistan active, others coming soon)
  - Success stories, scholarships, and resources

## 🛠️ Tech Stack

- **Framework**: Nuxt 3
- **Styling**: Tailwind CSS
- **Fonts**: Syne (headings), Inter (body)
- **Image Optimization**: @nuxt/image

## 📦 Installation

```bash
# Install dependencies
npm install

# Development server (http://localhost:3000)
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
